# 本命征象显著性筛选协议

本命盘不采用“每个征象平均分配篇幅”的写法。先找能解释主题主轴的少数结构，再处理补充证据。

## 优先级

| 级别 | 进入正文条件 | 用途 |
|---|---|---|
| `critical` | 直接命中主题宫主/核心聚集，并能改变责任链 | 必须进入主题结论 |
| `high` | 与主题责任链相连，且有明确行星状态、尊贵或交付条件 | 进入正文，作为主要分辨项 |
| `supporting` | 单一相位、次要飞宫、弱辅助征象，不能独立改变结论 | 延后到 JSON 审计层，默认不写进正文 |
| `context` | 历史背景、Joys、来源争议或未经确认的技术线索 | 只作研究附录，不作个人断言 |

## 选择规则

1. 每个主题模块声明 `minimum_salience` 与 `max_primary_rules`；默认只输出 `critical/high`。
2. 同一主题最多保留少数主征象，避免多个相似句子稀释真正的主轴。
3. 被延后的征象不会被删除，而是进入 `deferred_evidence`，便于未来补充度数、运动、接纳或现实观察后重新评估。
4. 单一外行星相位、宽orb相位、没有主题宫主责任的征象，不能因为措辞强烈而越级。
5. 重要程度由“主题相关性 × 责任链位置 × 交付证据 × 独立重复支持”共同决定，不以传统术语的神秘程度决定。

## 当前真实星盘的应用

当前报告优先保留：2/10宫与火星的财富—职业交付链、4宫太阳/月亮/水星聚集、7宫主土星落9宫，以及木星6宫的工作负荷结构。金星六合、福点、外行星和未确认运动状态的相位暂不进入主结论，只保留为可追溯辅助证据。

这不是否认弱征象，而是先避免“重要结构被低信号信息淹没”。当用户提出具体主题，或补齐度数、运动、现实验证后，延后征象才可重新升格。
