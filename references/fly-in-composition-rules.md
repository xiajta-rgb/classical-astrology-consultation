# 飞宫组合判断规则

本文件沉淀本轮验证出的可复用解释规则。它是项目的组合层规则，不能替代本地排盘、宫主计算、尊贵审计或时限技术。

## 1. 方向不是对称的

`A宫主落B宫`只表示A宫责任进入B宫语境。反向关系必须单独计算，不能把一条飞宫倒读成另一条。

- `4飞2`：房产、土地、不动产责任进入财富宫，较直接支持“房产成为财富来源”。
- `2飞4`：个人收入、积蓄和资源进入房产宫，较直接支持“用钱置业、财富沉淀到房产”。
- `4飞11`：房产责任进入收益宫，支持不动产回报假设。
- `11飞4`：收益回流房产，支持把收益转为不动产配置。

`2飞4`不能单独升级为“房产获利”；必须另有`4飞2`、`4飞11`、4宫与11宫的双向连接，或独立的收益与时限证据。

## 2. 责任链要分层

- `4飞5`：房产进入子女、教育、创作或长期投入语境；在现实材料支持学区/子女主题时，优先解释为教育型居住安排。
- `8飞5`：贷款、共同资金或长期财务责任进入子女/教育/5宫投入；不能自动写成房贷，须结合4宫和现实问题。
- `8飞6`或`6飞8`：债务与工作、日常劳务形成互相牵制；没有这条实际飞宫，不能把“8宫债务”直接写成“工作收入被绑定”。
- `10飞9`：事业进入专业、教育、法律、远景规划或跨地域语境；不能直接写成职位变动或收入增长。

## 3. 吉利、 中性与压力不能只看飞入宫

飞宫只说明责任流向；交付质量还要检查：

1. 宫主的本质尊贵、失势、逆行、燃烧和sect；
2. 落宫的角性、续宫性或陷宫性；
3. 吉凶星的相位、接纳和应用/分离状态；
4. 2宫、11宫、福点对收益兑现的支持；
5. 6宫、8宫、12宫对成本、债务和消耗的反证。

## 4. 互容不是宫位对经验表

严格行星互容必须有双方互在对方的尊贵中，并通过项目的typed reception与连接审计。宫位对互容表只能作C级候选假设，不能称为已经发生的古典互容，也不能单独产生财富、婚姻或债务结论。

## 5. 房产获利的发布门槛

只有下列证据汇聚时，才可以使用“房产获利/不动产回报”这种强表达：

- `4飞2`或`4飞11`为主链；
- 4宫主具备交付能力，并得到木星、金星、福点或2/11宫主的独立支持；
- 没有足以抵消的8、12、6宫压力；
- 若涉及未来年份，还必须通过timing activation gate。

若只有`2飞4`，应写“财富配置到房产”“房产成为资产载体”，不写“房产带来利润”。

## 6. 本轮22:35盘的应用记录

脚本输出的核心方向为：`2飞4`、`4飞5`、`5飞7`、`8飞5`、`10飞9`、`11飞5`、`12飞5`；严格行星互容为空。

因此本盘的优先解释是：个人财富进入房产；房产服务子女教育；长期财务责任进入5宫投入；事业通过9宫专业/知识/长期规划展开。不能把它升级成`4飞2`式的不动产直接获利格局。

## 7. 每次发布必须保留的追踪字段

`chart_engine -> fly_in_calculation -> validated_direction -> reference_rule -> counter_test -> conclusion_grade`

没有这条追踪链，飞宫结论只能停留在未发布的内部假设。
