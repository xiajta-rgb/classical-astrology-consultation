# 研究迭代 LOOP 体系

> 版本：LOOP-1.0
>
> 目标：让每一份星盘文档都能快速呈现全貌、明确指出主矛盾，并且经得起来源、反证、反泛化和敏感主题审查。
>
> 当前优先级：先完成 [NATAL-1.0 本命优先架构](natal-first-architecture.md)；未来时限只作为后续插件。

## 一、LOOP 的四个阶段

### L — Locate / Load：定位与加载

输入必须先被限定：

```text
question: 用户真正要判断的主题
chart_contract: 星历、黄道、宫制、地点、出生时刻精度、度数完整性
risk_level: G0 / G1 / G2 / G3
source_scope: 本轮允许调用的来源 ID
```

门槛：

- 没有出生时间、宫制或度数时，不得假装拥有精确的宫主、相位或事件时间。
- 用户未主动提出 G1/G2 主题时，不主动展开敏感内容。
- G3 主题只能做边界说明和现实支持转介，不产出确定性预测。

### O — Organize：组织证据与竞争假设

先建立 `Chart Facts`，再建立主题责任链：

```text
事实 -> 宫位责任 -> 宫主落点 -> 尊贵/状态 -> 相位/接纳 -> 时限 -> 现实翻译
```

每个主题至少生成两个假设：

```text
H1: 领先解释
H2: 竞争解释
limit: 仍无法区分的部分
```

每条证据必须记录：来源 ID、章节/页码、规则、适用条件、独立支持、反证、现代状态。

### O — Oppose / Overfit Test：反证与过拟合测试

这一阶段专门攻击最有吸引力的结论：

1. **反证测试**：找至少一条削弱或转向该结论的因素。
2. **换盘测试**：替换一个宫位、主宰或星体后，句子是否仍然成立？若仍成立，说明它太泛。
3. **去重测试**：同一事实是否被“落宫、主题、性格、优势”重复计算？只算一次。
4. **条件测试**：结论是否明确写出“在什么条件下才成立”。
5. **敏感主题测试**：是否把历史词汇误写成现代诊断、身份、犯罪或死亡断言。
6. **现实可观察测试**：能否翻译成决策、资源、关系、工作或制度行为，而不是抽象形容词。

### P — Publish / Promote：发布与升级

只有通过发布门槛的结论才进入最终文档：

```text
核心判断 -> 证据结构 -> 结构性优势 -> 结构性矛盾 -> 主题结论
-> 风险边界 -> 咨询建议 -> 不可判断项 -> 研究轮次与来源
```

结论使用 `S/A/B/C/N/A`：

- `S`：两条以上独立主证据，无重大未解决反证。
- `A`：一条主证据 + 一条独立支持，有明确限制。
- `B`：真实但单点的倾向，只能作为有限判断。
- `C`：辅助征象，不能单独定论。
- `N/A`：数据或技术不足，明确停止推断。

## 二、直指问题核心的表达协议

“突破禁忌”在本系统中定义为：不回避资源、控制、债务、亲密边界、权力、失败、损失和制度约束等难题；但仍不把历史禁忌标签变成现代人的确定性罪名、疾病或命运宣判。

### 核心句格式

```text
主体 + 结构指向 + 发生机制 + 可观察表现 + 限制条件 + 证据等级
```

示例模板：

> 这组配置首先指向“共享资源与控制权绑定”，不是泛泛的“关系复杂”；其机制是 7/8 宫主与 2/10 宫主互相牵制，现实中更容易表现为分账、债务、授权和退出条件反复拉扯。若缺少应用相位或时限，不能把它升级为具体事件。（A）

### 禁用的水文替代

下列词语不能单独构成结论：

`有潜力`、`比较敏感`、`需要平衡`、`可能会成长`、`人生有变化`、`适合长期主义`、`能量很强`、`关系复杂`、`注意情绪`、`有贵人`。

必须替换成：谁、哪一宫/宫主、什么机制、在什么情境、会如何表现、受什么限制。

## 三、多轮研究与测试循环

每轮必须留下可复核记录：

```text
round_id: LOOP-YYYYMMDD-N
question_scope: [本轮问题]
sources_read: [Rxx / QI-xxx]
candidate_rules: [新增或修改的规则]
tests_run: [T01...T07]
failures: [失败样例]
changes: [纳入 / 降级 / 撤回 / 待核读]
result: [pass / partial / blocked]
next_round: [下一轮最小任务]
```

### 最少三轮

**第 1 轮：来源与抽取**

- 读取原典/学术文献，建立 Quote/Insight Cards。
- 每条洞见必须有 locator 和版本限制。

**第 2 轮：规则与反例**

- 将洞见转成候选规则。
- 为每条规则写支持案例、竞争假设、反证和缺失判别数据。

**第 3 轮：文档与回归**

- 用代表性命盘或合成 Chart Facts 生成文档。
- 运行水文检测、证据链检测、敏感主题检测、全貌覆盖检测。
- 失败时降级或撤回规则，不得为了“完整”硬填结论。

## 四、专业文档的“全貌快照”

最终文档开头必须在 30 秒内回答：

1. 这个人的主要资源/能力交付路径是什么？
2. 最大结构性矛盾是什么？
3. 哪个主题最容易产生现实代价？
4. 哪些判断最强，哪些只能保留为假设？
5. 什么事情本命盘无法确认？

覆盖域至少包括：`自我与决策、职业与公共角色、金钱与共享资源、关系与家庭、创作/子女、压力与风险、时限边界`。没有材料的域写 `N/A`，不以通用话术补齐。

## 五、失败处理与回滚

- 来源不可定位：`不纳入`。
- 只有单一醒目征象：最高 `B`。
- 反证未处理：不得 `S`。
- 结论换盘仍成立：删除或改成具体机制。
- 敏感主题越过 G3：立即撤回该句，改为边界说明。
- 新规则破坏既有回归样例：保留旧版本，标记新规则 `candidate`，不发布。

LOOP 的完成不是“写得更满”，而是“核心判断更少、更准、更可追溯；不确定处明确停止”。
