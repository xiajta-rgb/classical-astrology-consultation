# 全域研究战役：2026-08-14

## 目标

在不把网络噪音当成证据的前提下，扩大到帖子、文章、书籍、原典、学术研究和跨传统材料，持续寻找能够：

- 改变本命判断顺序或证据权重的规则；
- 解释隐晦技术为何成立、何时失效的条件；
- 揭示传统内部冲突、传本误读和现代心理偏差；
- 让最终文档更具体、更短、更直接，而不是更长。

## 七条检索线

### A. 本命古典核心（最高优先级）

托勒密、瓦伦斯、Dorotheus、Firmicus、Masha’allah、Sahl、Abu Ma’shar、Bonatti、Lilly。

重点：宫位责任、宫主链、sect、尊贵、角性、可见性、接纳、相位、福点/灵魂点、职业、财富、婚姻、子女、家庭和资源约束。

### B. 隐晦技术

反照点、反反照点、Lots、月相、界/terms、面、十二分盘、固定星、行星光束、围困、应用/分离、dexter/sinister、dispositor 交付链。

原则：隐晦不等于高权重；只有在来源、计算、适用条件和反例都清楚时，才允许从辅助层升级。

### C. 未来时限（暂存，不覆盖本命）

profections、transits、secondary progressions、primary directions、zodiacal releasing、solar returns、年限和主限。

当前只登记方法，不让它们参与本命文档的先验判断。

### D. 世俗、政治与制度层

日月食、木土会合、国家/城市图、战争、政权和制度周期。

用途：研究“个人结构”与“环境条件”如何区分；不把世俗征象倒灌到个人本命盘。

### E. 医学史、身体和禁忌主题

研究古代体液、疾病和寿命术语的历史语境；现代输出必须经过敏感主题协议，不做诊断、死亡预测或身份指控。

### F. 学术史与现代实证

Barton、Beck、Lehoux、Kassell、Carlson、Fichten、Tyson、Allum 等。

用途：区分“传统曾这样说”“这套方法如何形成”“现代测试支持到哪里”，避免把三种命题混为一谈。

### G. 帖子、论坛和案例

论坛帖子、博客、播客和案例只进入 `hypothesis_pool`，除非同时满足：

1. 有完整或足够的星盘数据；
2. 有明确问题、方法和结果；
3. 有失败案例或反例；
4. 能回溯到原典/学术来源；
5. 不靠事后挑选成功案例。

帖子可以启发研究，不得单独升级 `S/A`。

## 质量蒸馏流程

```text
广搜
→ 去重
→ 来源分级
→ 版本/章节定位
→ 短摘录或忠实转述
→ 规则候选
→ 支持案例 + 反例
→ 本命回归测试
→ 敏感主题与反泛化测试
→ 纳入 / 辅助 / 待核读 / 撤回
```

## 本轮已确认的新增方向

- 反照点应作为“隐性连接候选”，不能替代实际相位。
- 福点/灵魂点涉及公式和昼夜盘分歧，必须做版本控制。
- 接纳必须记录尊贵类型、方向和相位连接，不能泛称“有缘分”。
- 传统相位的容许度属于行星能力与可见性体系，不应机械套用固定度数。
- 界/terms 具有多套历史系统，不能在同一盘中混用而不声明。
- 体液/气质材料应当作为医学史，不得转写为现代疾病诊断。
- 论坛案例最容易产生确认偏误，必须放在假设池而非证据层。

## 当前突破点

本系统的“突破”不依赖增加更多玄秘名词，而依赖三个改变：

1. **从单象征转为交付路径**：不只问“某星代表什么”，而问“它主宰什么、落在哪里、能否交付、通过谁交付”。
2. **从漂亮解释转为竞争假设**：同一配置同时保留资源、义务、控制、损失等方向，直到独立证据区分它们。
3. **从更长文档转为更高信息密度**：开头先给最强的 5–8 条判断，再展示证据、反证和不可判断项。
