# 多重征象组合与抽象推理框架

## 目标

不穷举“行星 × 星座 × 宫位 × 相位”的组合，而是把每个征象拆成可组合的功能字段，再从有限案例中提炼稳定的互动模式。案例提供参数、反例和边界；框架负责迁移到新命盘。

## 征象的七个功能槽位

每条征象先标准化为：

```text
subject      谁/什么被描述（盘主、母亲、伴侣、职业、资产、居所）
domain       哪个现实领域（1/2/4/5/6/7/8/10/11 等责任域）
responsibility 由哪个宫位/宫主承担什么责任
carrier      哪颗行星承载该责任
condition    尊贵、失势、sect、角宫、速度、可见性等交付能力
connection   相位、接纳、互容、定位链、轴线或同宫连接
activation   本命持续结构，还是由时限技术触发
```

星座通常进入 `condition` 和 `mode`，不能单独占据 `domain`；行星本质通常进入 `carrier/function`，不能独立替代责任链；宫位先确定现实领域，再解释行星如何把该领域带入另一处。

## 组合运算符

### 1. 责任转移（responsibility → placement）

宫主把一个领域的责任带入另一宫。它回答“哪个现实主题通过什么场所、关系或资源交付”，不是“这个人有什么性格”。

### 2. 能力调制（responsibility × condition）

同一责任因尊贵、sect、角宫、速度、可见性或受克不同，表现为顺畅交付、延迟交付、代价交付或交付受阻。条件改变交付方式，不凭一项条件决定成败。

### 3. 连接与交付（carrier × connection）

相位、接纳、互容和定位链说明两个责任是否能互相传递；无连接时保留“有意向/有资源”与“能落地”之间的差别。

### 4. 领域汇聚（independent convergence）

不同来源的责任链指向同一现实机制时，形成主题汇聚。例如二宫、十宫和十一宫分别通过独立链条指向“技能—交付—收益”，比三句重复的“有财运”更有信息量。

### 5. 资源冲突（support × constraint）

吉性支持和限制因素同时出现时，不互相抹除，而翻译为带成本、延迟、条件或选择代价的结果。

### 6. 瓶颈（many responsibilities → one weak carrier）

多个主题集中到同一颗能力不足或受限的行星时，抽象为交付瓶颈。不要把同一颗行星重复算成多条独立证据；要识别它承载的共同机制。

### 7. 反馈/递归（ruler chain returns or repeats）

定位链回到起点、重复同一宫位或形成封闭回路时，判断为自我强化或反复回到同一现实问题，而不是增加一个新的“征象数量”。

### 8. 轴线转译（opposed domains）

4/10、2/8、1/7、5/11、3/9 等轴线把私人/公共、个人/共享、主体/关系、产出/社群、近端/远方之间的资源和责任拉成张力。

### 9. 角度阈值（angularity × precision）

角宫、精确度数、入相和可见连接共同决定“是否容易成为现实主轴”；仅有符号相似或宽泛同元素，不足以升级。

## 从有限案例提炼规律

每个案例不保存为“固定组合答案”，而保存为：

```text
输入槽位 → 组合运算符 → 现实机制 → 可观察表现 → 反例/替代机制 → 适用边界
```

例：`月亮(家庭/身体) + 四宫(根基) + 天蝎(固定、防御、月亮落陷) + 冥王星(现代深层辅助)` 不保存为“必然家庭创伤”，而抽象为：

```text
私域情绪/照料责任
→ 家庭安全、边界或资源治理
→ 固定化的保护与重组机制
→ 居所变化、照料责任、家族权力/资源重新分配等候选表现
→ 也可能只是盘主的私人修复空间或研究/照护能力
```

## 多重征象的证据权重

1. 先按独立责任链去重，再看同一机制是否汇聚。
2. 责任链优先于本质关键词；交付能力优先于形容词；现实机制优先于人格标签。
3. 同向证据提高“主题稳定性”，不自动提高事件严重性。
4. 冲突证据生成“条件结果”，不简单平均分数。
5. 时限只负责触发本命机制，不改变本命机制本身。
6. 高风险事件候选必须经过完整父母/死亡/疾病等专项协议，不能由组合数量直接升级。

## 输出结构

```text
主机制：哪些责任通过哪个载体交付
组合动力：汇聚、冲突、瓶颈、反馈还是轴线张力
现实表现：可能出现在哪些事件/决策/资源/关系行为
竞争解释：至少一个同样能解释现象的替代机制
升级条件：还缺什么度数、相位、现实资料或时限
```

没有主机制和现实表现的组合，只能作为 `context_only`；没有独立证据的重大事件，只能作为内部 `candidate/N/A`。
