# Round 120 状态

当前发布决策：`HOLD`

## 当前能解读

- 用户提交的行星宫位、宫头星座、飞宫声明、相位声明和接纳声明可以作为已声明事实与候选结构进行审计。
- 可以输出宫位责任链、候选尊贵主宰、相位几何类别、连接状态和明确的未知项。

## 不能解读

- 不能把当前材料升级为精确本命定论、应用/分离相位、确定性接纳或未来事件预测。
- 不能根据缺失的速度、逆行、可见性或出生契约字段进行补推。

本轮新增：

- 行星状态层新增 `motion_visibility`：速度、逆行和可见性只接受输入中明确声明的字段。
- 缺少速度/逆行/可见性时分别输出 `unknown_due_to_missing_motion`、`unknown_due_to_missing_visibility`；负速度不会自动推断逆行。
- 完整、稀疏、速度单独声明和畸形输入分支均有回归测试。
- CET 适配器补充非成功状态与非对象 JSON 失败分支；错误响应在进入标准化层前被拒绝。
- 重新生成用户事实、来源审计、研究资产、假设卡、报告、发布清单和 SHA-256 工件清单，避免继续使用 Round118 的旧事实快照。

当前仍不能解除 HOLD：

- 用户原始出生年月日、准确时间、地点/经纬度、时区、黄道制和宫制未形成完整 Chart Contract。
- 用户盘相位缺少度数及应用/分离运动证据；接纳缺少实际相位连接证据。
- P0 来源仍缺可核验全文/完整方法结果，按停止条件不升级占星有效性结论。

机器门禁：`decision=hold`；`publishable=false`；Round120 工件指纹待发布前验证。
