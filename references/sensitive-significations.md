# 敏感、隐晦与禁忌征象协议

## 目的

古典文献保存了大量关于死亡、疾病、性、精神状态、犯罪、奴役、诅咒和社会污名的历史语言。这些材料可以帮助理解传统占星的知识史和规则结构，但不应直接变成现代人的诊断、指控或命运宣判。

本协议把“可研究”与“可输出”分开：允许记录历史征象，不允许把历史标签原样贴到当事人身上。

## 分级处理

| 级别 | 处理方式 | 典型主题 |
|---|---|---|
| G0 普通 | 可进入常规证据链 | 财务结构、职业、迁移、一般关系议题 |
| G1 敏感 | 需要用户明确主题、使用中性语言、展示限制与反证 | 婚姻、性关系、生育、子女、家庭冲突、债务 |
| G2 高风险 | 只能做历史/结构性讨论，不给事件断言；必要时建议现实专业支持 | 疾病、精神健康、暴力、犯罪、诉讼、成瘾、严重贫困 |
| G3 禁止确定性输出 | 不预测、不诊断、不指控、不确认 | 死亡日期/方式、自杀、他人犯罪、诅咒附体、性取向、怀孕结果、流产/不孕、医疗或投资结果 |

## 传统材料的可用范围

### 死亡、寿命与灾祸

- 可研究：Ptolemy *Tetrabiblos* Book III 的寿命/主限和 Book IV 的死亡章节；Valens 关于角宫、福点、时限的案例结构。
- 只能输出：哪些宫位/主宰链被传统方法视为“需要关注的脆弱点”，并明确本命盘无法确认死亡时间、方式或必然性。
- 必须加入：现实健康与安全资料优先；若用户存在现实危机，先转安全支持，不继续玄学推演。

### 疾病、身体与精神健康

- 可研究：Ptolemy Book III 的身体伤病和精神疾病章节；Valens 的行星/星座身体对应。
- 禁止：把星座/行星对应写成现代疾病诊断、残疾判断、精神障碍标签或用来替代医生；尤其禁止建立“癌症星盘征象”或用本命盘排除癌症。
- 中性翻译：使用“传统文本把此类配置与某类身体压力/生活负担联系起来”，不要写“你会得某病”。
- 现代边界：癌症必须遵循临床病史、体检、实验室/影像及必要的活检等医学流程；占星材料只能作为历史知识，不能提供诊断或预后。

### 性、婚姻、生育与子女

- 可研究：Ptolemy Book IV marriage/children；Valens 的同居、婚姻、子女和生育材料。
- 禁止：从星盘推断性取向、性别认同、忠诚与否、强奸/乱伦事实、怀孕结果、流产、不孕或子女健康。
- 允许：在用户主动且自愿的前提下，讨论关系契约、共享资源、亲密边界和照护压力等结构性主题。

### 暴力、犯罪、监禁、奴役与战争

- 可研究：Valens、Bonatti、Lilly 中关于束缚、诉讼、敌手、流放、服务/奴役的历史语境。
- 禁止：预测某人会犯罪、会施暴、会被捕，或用星盘为现实指控提供证据。
- 允许：讨论“冲突/制度约束/资源被扣留”的象征模型，并要求现实法律事实与证据独立核验。

### 诅咒、附体、巫术与“禁忌力量”

- 可研究：把它们作为古代作者的世界观、隐喻和社会史材料。
- 禁止：确认用户被诅咒、附体、下蛊或被某人施法；禁止提出驱邪、付费解厄等高风险建议。
- 中性翻译：如“传统文本会把这种体验解释为隐秘压力/恐惧/排斥”，同时保留现实心理、社会和医疗解释。

### 社会污名与身份标签

古典文本中的“卑贱、变态、疯癫、私生、残废、同性恋”等词汇带有强烈时代偏见。它们只能作为原文历史语境的索引，不能作为现代输出词汇，也不能被当作行星本质。

## 输出闸门

```text
1. 用户是否主动提出该敏感主题？否 -> 不主动展开。
2. 是否有明确的现实语境与咨询目的？否 -> 只做一般历史说明。
3. 是否把历史标签改写为可观察的中性机制？否 -> 不输出。
4. 是否存在至少两条独立证据和一个反证？否 -> 降为 B/C 或 N/A。
5. 是否会被误读为医疗、法律、财务或安全结论？是 -> 加专业转介与现实核验。
6. 是否触及 G3 禁止项？是 -> 明确拒绝确定性断言，转向安全、可验证的现实问题。
```

### 本轮敏感专题的最小输出集合

```text
死亡/寿限 -> 仅历史技术结构，不给日期、方式或年龄
疾病/癌症 -> 仅历史身体象征与就医边界，不给病名诊断
破财 -> 仅现金流、债务、合同和共同资源风险，不给破产保证
出轨/淫乱 -> 仅契约、边界、公开性和信任机制，不作事实指控
父亲/母亲 -> 仅家庭责任、资产、距离和照护结构，不预测父母寿命/病亡
```

## 记录模板

```text
topic: [主题]
source_id/chapter: [出处]
historical_phrase: [仅供内部核读的历史措辞]
neutral_translation: [中性结构翻译]
supporting_testimonies: [独立证据]
counter_testimony: [限制/反证]
risk_level: [G0/G1/G2/G3]
output_status: [可输出 / 仅历史参考 / 禁止确定性输出]
```

## 现实观察记录的隐私闸门

现实观察不是默认可以收集的“验证材料”。如果观察陈述触及 G1/G2 敏感主题，必须记录用户主动提出、最小化陈述和风险等级；G3 内容不进入可发布证据。系统只保留能区分 H1/H2 的最小必要事实，不保存与判别无关的身份、医疗、性或法律细节。

敏感词检测使用可版本化的类别词典，兼容中英文、空格/连字符变体和常见隐喻；命中类别与版本进入审计，不能因词典更新而静默改变历史报告。
