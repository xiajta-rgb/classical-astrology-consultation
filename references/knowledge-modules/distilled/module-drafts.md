# 公众号占星候选模块草案

本文件是从 `exploration.json` 生成的边界草案，不是核心规则库。所有模块均为 candidate-only / C 级；来源集中于一个公众号账号，必须经过独立来源、反例和机器回归。

## 时限与激活边界候选 (`timing_deferred`)

- 层级：`deferred_research`；卡片数：11；状态：`candidate_only`；证据上限：`C`。
- 纳入边界：只登记行运、返照、推运、法达、校时等方法的条件与资料需求。
- 排除边界：不从本命候选卡直接生成年份、月份、日期或确定事件。
- 下一测试：用户明确时间问题后，锁定出生时间精度、方法版本、计算数据，并加入反例。
- 代表卡：`AAD-00335` “最限制身高”的本命配置；`AAD-01826` 不可忽视的合盘冲相位；`AAD-00912` 水星逆行者的八点优势；`AAD-01755` 有关“秘密”的十大本命要点；`AAD-01659` 大格局人到底强在哪里？

## 宫位、轴点与宫主责任链候选 (`house_rulership`)

- 层级：`candidate_structure`；卡片数：39；状态：`candidate_only`；证据上限：`C`。
- 纳入边界：把宫位、角点、宫主和飞宫片段整理为责任主体—承载宫位的待验证链条。
- 排除边界：宫位标签不能单独推出身份、健康、灾难或社会结果；不混用未锁定宫制。
- 下一测试：用至少两份独立来源和合成 Chart Facts 检验责任链、重复计数与反例。
- 代表卡：`AAD-00160` 本命盘“木星”的八个秘密；`AAD-00333` 本命盘中的“日月合壁”；`AAD-00344` 本命盘中的“第一尊贵星”；`AAD-00593` “胖”星 与 “瘦”星；`AAD-01249` 《你可能不知道系列》之下降篇

- 层级：`candidate_structure`；卡片数：24；状态：`candidate_only`；证据上限：`C`。

## 关系、家庭与合盘适配候选 (`relationship_adapter`)

- 层级：`domain_adapter`；卡片数：14；状态：`candidate_only`；证据上限：`C`。
- 纳入边界：将关系、家庭、伴侣和合盘词汇作为领域适配入口，不改变底层责任链。
