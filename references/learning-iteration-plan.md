# 占星解读学习训练迭代计划

本计划把用户在多轮咨询中的纠正，转化为可复用的路由、规则、回归样例和发布门槛。它是用户触发、范围受限的迭代流程，不代表系统在后台自动学习。

## 一、固定训练顺序

### 第1层：数据与边界

先锁定出生时间精度、地点坐标、黄道、宫制、昼夜盘和上升边界。21:30与22:35这种分支必须重新排盘，不能沿用上一分支的宫主关系。

### 第2层：主题路由

根据问题选择最小充分模块：

- 房产/财富：4、2、8、10、11；4宫主入5宫时叠加5、1、4、8；
- 子女教育：5、5宫主、1、4、8；
- 事业/收入：10、10宫主、1、6、2、11、7；
- 债务/共同财务：8、8宫主、2、6、7、4；
- 未来问题：本命完成后再启用指定推运技术。

### 第3层：飞宫方向审计

先由脚本输出宫主飞入宫位，再解释方向。`4飞2`与`2飞4`不是同一件事：前者把房产责任带入财富宫，可支持房产成为财富来源；后者把财富责任带入房产宫，主要表示资金配置到房产。

同样，`4飞5`优先解释为房产进入子女/教育语境；`8飞5`表示长期财务责任进入子女或教育投入；只有实际存在`8飞6`或`6飞8`时，才可把债务直接写成工作与现金流反馈。

### 第4层：行星交付能力

飞宫只是责任方向，必须继续检查宫主的尊贵、失势、逆行、sect、角性、相位、接纳和福点。吉星落入某宫不等于结果自动良好；凶星落入某宫也不等于事情必然失败。

### 第5层：组合与反证

每条重要结论都写成：

`Chart Fact → 古典规则 → 责任链 → 现实机制 → 支持证据 → 反证 → 等级`

单个配置只能形成候选解释。只有多个独立责任链汇聚，才可以提高等级；同一颗行星重复出现在不同句子中，不得重复计分。

### 第6层：时限

本命只判断结构，不直接给年份。用户明确询问未来后，才调用年限、法达、次限、太阳弧、太阳回归或其他登记技术；没有直接激活本命责任链时，输出`deferred`。

### 第7层：双文案渲染

古典版显示宫位、宫主、尊贵、相位和等级；委婉版隐藏术语，但必须保留“明确支持、混合、有压力、证据不足”等判断力度，不得把强征象改写成“也许有帮助”。

## 二、本轮已经沉淀的核心经验

1. **方向性优先**：飞宫不可倒读；4飞2与2飞4分别代表财富来源和财富配置。
2. **责任链优先**：4飞5不是泛泛的“家庭重要”，而是房产责任进入子女/教育语境。
3. **债务落点要实证**：8宫主落6宫才支持债务进入工作；8宫主落5宫则优先指向子女教育、5宫投入或长期项目。
4. **资产与获利分开**：2飞4可以说明钱进入房产，不能单独升级为房产获利。
5. **严格区分互容**：宫位对经验矩阵是C级辅助；严格行星互容需要双方尊贵方向和连接审计。
6. **时间分支必须重算**：22:35盘需要重新确认2、4、5、6、8、10宫宫主，不能把21:30盘的8飞6或10宫落木星结论直接搬过去。
7. **事业判断不能事件化**：10宫强或10宫主有力，可以判断职业交付能力；不能仅凭本命指定换岗、换平台或收入延迟。
8. **现实句必须有征象**：删除“谁都适用”的句子，例如“事业会影响家庭”“收入承担房贷”；改写为具体宫主方向和可观察机制。
9. **委婉不等于削弱**：去掉术语，不去掉证据等级、主导征象、限制征象和预测边界。
10. **每次用户纠正都要入回归集**：纠正必须记录失败句、正确征象、规则、反证和测试命盘，不能只在当前回答中临时修补。

## 三、训练样本与回归安排

第一批回归样本固定使用陈月朋21:30与22:35两个时间分支，检查：

- 宫主飞宫方向是否一致计算；
- 4飞5、2飞4、8飞5、10飞9是否被正确区分；
- 是否错误输出4飞2或8飞6；
- 是否把2飞4升级成房产获利；
- 是否把无互容写成互容；
- 当前推运是否经过时限激活门槛；
- 古典版与委婉版是否保持同一证据等级。

每轮用户新增纠正，都按`lesson_card_schema`加入配置文件，并至少通过两个独立命盘或两个出生时间分支的反向测试，才允许把候选经验提升为更高等级。

## 四、发布前最小检查

发布任何飞宫、互容、房产获利或未来预测结论前，必须能回答：

1. 这条结论由哪个脚本计算；
2. 它属于哪条有向责任链；
3. 是否存在反向或相反链条；
4. 行星状态是否支持交付；
5. 是否有独立相位、接纳或互容连接；
6. 结论是结构、机制、建议还是预测；
7. 哪个条件会使它降级；
8. 文案是否仍然具体到这张盘，而不是对任何人都成立。
