# 1997-08-03 05:05 周宁｜星盘洞见账本

## 本命核心

- 狮子上升；太阳、月亮在一宫；水星、金星在二宫。
- 二宫主太阳落一宫：个人能力、身份和收入直接相连。
- 三宫主/十一宫主水星落二宫：沟通、文书、技能和收益进入个人财富。
- 四宫主金星落二宫：家庭、居住、房产议题通过资金、交易和价值管理落地。
- 十宫主火星落三宫，对冲九宫土星：事业靠信息、合同、学习和执行交付，但受机构规则、授权和制度延迟制约。
- 六、七、八宫主土星落九宫；五、九宫主木星落七宫：工作健康、教育、伴侣和共同资源互相牵动。
- 太阳/月亮对冲七宫天王星：个人路径与合作对象/平台之间存在突然重排的结构。
